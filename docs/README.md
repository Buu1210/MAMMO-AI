# MAMMO-AI

Documentación del proyecto MAMMO-AI, una aplicación web de apoyo para el análisis preliminar de mamografías con un clasificador de aprendizaje profundo, mapas de calor Grad-CAM y un tutor de IA gamificado.

> **Aviso:** MAMMO-AI es una herramienta de apoyo académica. No emite diagnósticos médicos ni reemplaza el criterio de un profesional de la salud.
