# Simulación con tutor IA

Contendrá el módulo educativo gamificado.

- **Entregable de la EDT:** E6 Módulo de simulación con tutor IA.
- **Requisito que cubre:** 5.1 de la matriz de trazabilidad.
- **Qué hará:** presentar escenarios con mamografías de referencia, guiar al usuario con un tutor de IA y darle retroalimentación, incluidos casos en los que el modelo se equivoca, para fomentar un uso crítico de la IA.
- **Datos:** las sesiones y respuestas se guardan en la base de datos (tablas `escenario`, `sesion_simulacion` y `respuesta_escenario`).

**Estado:** pendiente de la fase de construcción.
