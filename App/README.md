# Aplicativo web

Contendrá la aplicación web por la que el usuario carga mamografías y consulta los resultados.

- **Entregable de la EDT:** E2 Aplicativo web.
- **Requisitos que cubre:** 2.1, 4.1 y 7.1 de la matriz de trazabilidad.
- **Qué hará:** recibir la imagen, enviarla al modelo, mostrar la clasificación preliminar con su nivel de confianza y el mapa de calor, y guardar cada análisis en la base de datos definida en `database/`.
- **Meta de calidad:** mostrar el resultado en menos de 10 segundos por imagen.
- **Aviso obligatorio:** los resultados se presentan como preliminares; la aplicación no emite diagnósticos.

**Estado:** pendiente de la fase de construcción.
